使用说明

  • 可导入各种 AI 工具的服装参考或图像参考功能。
  • 可按分类筛选，搜索编号或服装关键词（支持中英文，如：牛仔、蕾丝、白色）。
  • 点「上传服装」可手动添加自己的图片（可多选/拖拽）。每张都必须选择分类并填写关键词，否则无法保存。
  • 上传图片的编号会按所属分类累加（如春 SPR-0261、夏 SUM-0261；自定义分类可用自己的前缀）。
  • 上传的图片可以删除（卡片右下角 × 或放大后点删除）；内置的 1407 张初始图片不可删除。
  • 点分类栏末尾的「＋ 分类」可新增自定义分类，在上传时逐张指定。
  • 点「AI 设置」填好 DeepSeek API Key 后，点开任意一张图片，在右侧「AI 提示词」里点「生成」，就会为这件服装写一条英文文生图提示词，可改、可复制、会自动保存。
  • 点「下载原图」可拿到源站原图：本地镜像了 PNG 时给无损 PNG，否则退回 WebP。
  • 图片仅包含服装；面容、体型和背景请另外提供参考或指令。
